# Contributing to Torch

Use [TomByte/torch](https://github.com/TomByte/torch) for issues and pull requests. Read [AGENTS.md](AGENTS.md) for the inherited Rust architecture and coding conventions, and [README.md](README.md) for Torch build commands.

Preserve the local-only policy: no account requirement, built-in AI suggestions, telemetry, or Warp service integration. Keep ordinary shell completion and history intact. Retain upstream copyright and licence notices.

Run targeted checks for changed crates and format changed Rust files before submitting. Do not restore Warp release, sync, factory, or private channel-configuration automation.
